# engine-system 系统净化引擎

通过 Shizuku 拿到 ADB 级权限，清理 ColorOS 自带的广告。**只做在你这台手机上实测验证过的操作**，每一步都能撤销。

## 详细功能

### 1. ColorOS 配置档案
- 每个 ColorOS 大版本一份档案（`profiles/coloros-<版本>.json`），记录：广告组件包名、广告开关对应的系统设置键、设置页跳转入口。
- 每一项都有 `verified` 标记，**只有在 Find X7 Ultra 上实测通过的项才会被执行**；未验证的项只显示「去设置」引导。
- 系统大版本升级后，只需要更新档案，不用改代码。

### 2. 一键净化（覆盖套路 #1–#8、#10）
按风险从低到高选择手段：
1. 改系统设置（关开关）
2. 撤销权限（appops）
3. 禁用组件（`pm disable-user`）
4. 卸载组件（`pm uninstall -k --user 0`，保留数据，可恢复）

| 套路 | 典型操作 |
|---|---|
| 锁屏画报 | 关闭画报推荐；可选禁用画报组件 |
| 负一屏 | 关闭资讯/购物/游戏/服务卡片（不禁用负一屏本身） |
| 搜索热搜 | 关闭热门搜索、个性化推荐 |
| 第三方 App 开屏注入 | 关闭「商业化服务」；可选卸载 `com.opos.ads` |
| 自带应用推荐 | 关闭各 App 个性化推荐 |
| 商店 / 安全中心推荐 | 关闭推荐开关 |
| 快应用 | 禁用快应用平台 |
| 广告追踪 | 限制广告跟踪、重置 OAID |

Shizuku 改不了、只能在设置界面里关的项，提供「去关闭」按钮直达对应设置页。

### 3. 按 App 的权限净化（套路 #20、#23）
- 「限制悬浮窗/后台弹窗」：拒绝该 App 的悬浮窗权限和后台弹出界面权限。
- 「禁止读取剪贴板」：防止口令类跳转（代价：在该 App 内可能无法粘贴）。
- 关联启动（#21）：引导到 ColorOS 的自启动/关联启动管理页。

### 4. 操作日志与撤销
每次操作都记录：改之前的状态、执行的命令、结果。可以单项撤销，也可以全部还原。

### 5. 巡检
- 每天检查一次已执行的项有没有被系统改回（例如系统升级后）。
- 被改回就提醒你「N 项设置被系统恢复 [一键重新执行]」。

### 6. 崩溃日志采集
Shizuku 在线时，每 30 分钟读取一次系统崩溃记录，发现被拦截的 App 崩溃，就上报给 guard。

### 7. Shizuku 离线时
手机重启后 Shizuku 需要重新激活。离线期间**已经做过的改动照样生效**，只是暂停巡检和新操作，首页显示「Shizuku 未激活（不影响已生效项）」。

## 依赖
`data`、`core-rules`；第三方库 Shizuku API。

# engine-notify 通知过滤引擎

基于系统「通知使用权」，在营销推送弹出后立即把它清掉。

## 详细功能

### 1. 按规则清除营销通知
- 规则可以按 App、通知渠道、关键词三个维度组合。
- 内置规则：针对 ColorOS 自带的软件商店、主题商店、游戏中心、浏览器、搜索、负一屏，标题或正文含「限时 / 福利 / 领取 / 优惠 / 红包 / 热门 / 免费 / 推荐」的通知自动清除（这些 App 的更新、下载完成等正常通知不受影响）。
- 被清除的通知会记录标题，在「通知过滤」日志里能看到，点一下可以打开对应 App，不怕错过。

### 2. 学习你的习惯
- 同一个 App、同一个渠道的通知，你 7 天内手动划掉 ≥3 次，就问你「以后自动过滤？」。
- 点「是」生成规则；点「否」，30 天内不再问。

### 3. 不误伤
- App 设为「关」、临时放行中、或者总开关暂停时，不处理该 App 的通知。
- 常驻通知（音乐播放、导航、下载进度这类）一律不动。
- 不处理本软件自己的通知。

## 依赖
`data`、`core-rules`。

# 哨兵实际验收报告（模板）

> 使用方法：复制本文件为 `reports/acceptance-<YYYY-MM-DD>.md` 后填写。标准与方法来自 `testing/acceptance/PLAN.md`，不要在报告里改动标准。
> 每项填「结果、证据、结论」；结论只写 **通过 / 不通过 / 未执行**。不通过项按 PLAN 处理：修复 → 重跑受影响模块的关卡 → 重做该项，并在本项下追加「重测记录」。
> 证据（录屏、截图、事件表 CSV）放在 `reports/` 下或写明本机路径；录屏等大文件不提交 git。事件表导出：`testing/acceptance/scripts/export-events.sh [--since <毫秒>]`。

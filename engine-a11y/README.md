# engine-a11y 界面拦截引擎

基于系统无障碍服务，「看」屏幕上的按钮并替你点。负责网络层拦不住、必须在界面上处理的广告。

## 详细功能

### 1. 开屏跳过
- App 从桌面启动后的 5 秒内，查找「跳过」按钮并点击。
- 先用该 App/页面的专属规则，再用通用规则（识别「跳过 3s」「跳过广告」这类文字）。
- 同一条规则每次启动最多点 3 次，防止来回点。

### 2. 弹窗关闭
- 任何时候按规则点击真正的关闭按钮，避开「下载」「确认」这类陷阱按钮和伪关闭。
- 发现页面上默认勾选了「自动续费 / 连续包月」，弹通知提醒你。

### 3. 激励视频
| 模式 | 行为 |
|---|---|
| 静默播完（默认） | 识别到激励视频页 → 媒体音量临时调到 0 → 倒计时结束后自动点关闭 → 恢复音量。**奖励照拿。** |
| 直接拦截 | 不做界面处理，交给网络层拦截广告（可能拿不到奖励）。 |
| 每次询问 | 识别到激励视频页时弹出小窗：「静默播完 / 正常观看 / ☐记住」。 |

- 你点「看视频领奖励」这类按钮时，打开 60 秒奖励窗口，让网络层暂时放行广告，保证视频能加载出来（「直接拦截」模式不开窗口）。
- 音量调低前会先存档，即使中途你离开、或服务被杀，下次也一定恢复。

### 4. 跳转回退
两种情况会自动把你带回原来的 App，并在底部提示「已拦截 A → B 的跳转 [撤销]」：
- **启动跳转**：从桌面打开 App 后的 5 秒内，你没碰屏幕，它却直接跳到淘宝、拼多多这类 App。
- **摇一摇跳转**（App 的「摇一摇」开关打开时）：屏幕上出现「摇一摇 / 扭一扭」字样，你没点任何东西，App 却跳走了。

以下情况**不会**回退：你点过、滑过屏幕；从通知栏、分享、链接、最近任务打开的；中间回过桌面的；跳去的是系统界面、输入法、来电等。点「撤销」会打开目标 App，并记住这条例外，以后不再拦截。

### 5. 学习模式
你手动关掉一个弹窗后（弹窗出现 3 秒内点了「关闭 / × / 跳过 / 不感兴趣」），通知会问「以后自动关？」，点「是」就生成一条只对这个页面生效的规则。

### 6. 误伤探测
- 发现系统弹出「XX 已停止运行」→ 上报 guard。
- 同一 App 60 秒内被启动 ≥3 次 → 上报 guard。
- 你点了跳转回退的「撤销」→ 上报 guard。

### 7. 性能约束
- 只监听窗口切换、内容变化、点击、滚动几类事件；内容变化防抖 100ms。
- 当前页面没有任何规则时直接返回，不遍历控件树。
- 新 App 的 3 天观察期只影响网络层，界面引擎照常工作（点「跳过」风险极低）。

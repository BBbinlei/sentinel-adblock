# app 界面

用户唯一会看到的部分。原则：**家人只需要首页大开关 + 每个 App 的三档开关；每个自动操作都能撤销；出问题最多点两下就能放行。**

## 详细功能

### 1. 引导向导（首次启动，5 步，可跳过、可回来补做）
1. 激活 Shizuku（图示：开启无线调试 → Shizuku 启动 → 授权）
2. 授权 VPN（并建议开启「始终开启的 VPN」，**不开启**「屏蔽未使用 VPN 的连接」，避免 VPN 异常时断网）
3. 开启无障碍（含 ColorOS「允许受限设置」的图示）
4. 授予通知使用权
5. 电池设为「不限制」+ 在最近任务里锁定本 App

每一步点「去设置」直达对应系统页，返回后自动检测是否完成，完成的打 ✓。

### 2. 首页
- **大盾牌**：显示「防护中 / 已暂停 / 未开启」，点一下全部暂停或恢复；下面是「今日拦截 N」。
- **四个引擎状态行**：网络拦截、自动跳过、通知过滤、系统净化，显示正常 / 异常 / 待处理，点进去看各自的日志。
- **guard 提醒卡**：「XX 疑似受影响，已自动降级 [查看] [撤销]」。
- **警告条**：私人 DNS 会让拦截失效、Shizuku 未激活等。

### 3. 系统净化页
- ColorOS 广告项清单（已关 x / 共 y），每项显示状态。
- 能自动处理的「一键处理」，只能手动关的「去关闭」直达设置页。
- 卸载类操作二次确认。
- 「撤销记录」：查看每次操作，单项撤销或全部还原。

### 4. 应用页
- 列表：搜索、按拦截次数排序，银行/支付类标注「默认放行」。
- 详情：
  - 拦截级别三档：**关 / 标准 / 强力**
  - 高级（默认折叠）：开屏广告、激励视频（静默播完 / 直接拦截 / 每次询问）、摇一摇跳转、跳转回退、营销通知、限制悬浮窗/后台弹窗、禁止读取剪贴板
  - 「App 打不开？一键临时放行」（放行 24 小时）
  - 观察期中的 App 显示「观察中（还剩 N 天）」及将要拦截的域名列表

### 5. 规则页
- 订阅列表：名称、条数、更新时间、启用开关、错误提示。
- 我的规则：学习生成的规则，可删除。
- 添加订阅（地址 + 格式）、立即更新。

### 6. 快捷入口
- 下拉通知栏快捷开关「暂停拦截 5 分钟」。
- VPN 常驻通知上的「暂停 5 分钟」按钮（engine-vpn 提供）。

### 7. 视觉
Jetpack Compose + Material 3，跟随壁纸取色，支持深色模式；大字号（字体放大 1.3 倍）下布局不溢出。

## 依赖
`data`、`guard`、`engine-vpn`、`engine-a11y`、`engine-notify`、`engine-system`（只用它们的启动入口与 Koin 模块，界面逻辑只读写 data）。
